# Common Programming Naming Cases

Programming mein variables, functions, classes aur files ke naam dene ke liye kuch standard conventions hote hain. Inhe **Naming Cases** kehte hain.

## 1. camelCase

- **Format:** Pehla word lowercase, baaki har word ka pehla letter capital.
- **Example:** `userProfileName`
- **Kahan use hota hai:** JavaScript, Java mein variables aur functions ke liye.

## 2. PascalCase

- **Format:** Har word ka pehla letter capital, koi space ya separator nahi.
- **Example:** `UserProfileManager`
- **Kahan use hota hai:** Classes, Interfaces, aur Components ke liye.

## 3. snake_case

- **Format:** Sab lowercase, words ke beech underscore (`_`).
- **Example:** `user_profile_name`
- **Kahan use hota hai:** Python aur SQL databases mein.

## 4. kebab-case

- **Format:** Sab lowercase, words ke beech hyphen (`-`).
- **Example:** `user-profile-name`
- **Kahan use hota hai:** URLs, CSS classes, aur HTML data attributes mein.

## 5. CONSTANT_CASE (Screaming Snake Case)

- **Format:** Sab uppercase, words ke beech underscore (`_`).
- **Example:** `MAX_RETRY_LIMIT`
- **Kahan use hota hai:** Global constants aur configuration flags ke liye.
